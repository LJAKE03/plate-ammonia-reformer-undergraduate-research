# 实验平台后续规划

## 1. 当前定位

实验平台建设不是本轮本科生工作的主要任务。应先完成反应器结构、催化剂、浆料、涂覆和制造链条调研，再根据真实样机尺寸、接口、材料和工况确定平台。

当前仍以独立可控热源气体供热作为实验平台的基础设想，不提前转为发动机实机排气联合运行。

## 2. 后续分三个阶段

### 阶段I：冷态与密封验证

- 惰性气体气密性检查；
- 外部泄漏检查；
- 热侧和氨气侧串漏检查；
- 流道是否畅通；
- 冷态压降；
- 各流道流量分配。

### 阶段II：非反应换热

- 独立热气供给；
- 冷侧采用惰性气体或经批准的替代工质；
- 测量入口和出口温度；
- 测量板壁温度；
- 测量两侧压力和压降；
- 检查热量平衡和测量不确定度。

### 阶段III：催化反应

- 催化剂活化或还原；
- 氨气供给和尾气处理；
- 氨转化率；
- 氢气产量和产品气组成；
- 运行稳定性和催化剂失活；
- 高温条件下涂层和结构完整性。

## 3. 平台设备需要等哪些信息明确？

| 设备 | 需要先明确的信息 |
|---|---|
| 质量流量控制器（MFC） | 反应器设计流量、气体种类、压力和量程 |
| 热源加热器 | 热侧流量、入口温度、目标热负荷和允许压降 |
| 热电偶 | 板片结构、测点位置、温度范围和安装方式 |
| 压力传感器 | 设计压力、压降范围和测压口位置 |
| 气相色谱仪（GC） | 预期产品组成、检测限和采样方式 |
| 尾气处理装置 | 残余氨含量、氢氮组成、排放和安全要求 |
| 控制与联锁系统 | 气体切断、超温、超压、通风、泄漏检测和紧急停机 |

## 4. 安全要求

涉及氨气、氢气、催化剂还原、高温和压力系统的工作，必须由项目负责人组织安全评审。学生只能在完成培训、获得授权并遵循实验室批准程序的前提下参与。

不得自行购买气体、连接气路、修改安全联锁或开展反应试验。

## 5. 本轮需要做什么？

每个工作包只需提出与本方向相关的平台影响。例如：
- 涂覆工艺可能改变流道有效尺寸；
- 板片制造可能影响测温和测压位置；
- 催化剂形态会影响后续装填、涂覆和活化方式。

完整设备清单和采购预算留到样机方案明确之后。

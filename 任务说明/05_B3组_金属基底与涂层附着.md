# B3组：金属基底、表面处理与涂层附着调研

## 1. 调研目标

寻找适合高温氨分解板式反应器的金属板材料，并研究如何通过表面处理和底涂提高催化剂涂层的附着性与耐久性。

## 2. 重点比较的金属材料

| 材料 | 需要研究的重点 |
|---|---|
| SS314 / EN 1.4841 | 氨分解微通道研究中出现过的材料线索；核实其高温氨气氛适用性 |
| 310S / EN 1.4845 | 作为高温不锈钢候选，核实材料性能和加工情况 |
| 316L | 重点关注高温氨气氛下的渗氮、脆化等问题，不能只依据常温耐腐蚀性判断 |
| IN625 | 高温合金候选，比较性能、成本和加工性 |
| FeCrAl | 金属催化剂载体研究较多，重点关注预氧化和氧化铝涂层，但不能直接等同于不锈钢表面 |

不同牌号不能简单视为相同材料。某种材料在空气中表现良好，也不代表它在高温氨气环境中一定适用。

## 4. 需要研究的表面处理方法

- 脱脂和清洗；
- 喷砂或机械粗化；
- 酸洗、碱洗；
- 可控预氧化；
- 氧化铝或勃姆石底涂；
- 等离子处理或其他中间层处理；
- 涂覆前对焊接边界进行遮蔽。

特别注意：FeCrAl上的高温预氧化方法不能直接照搬到SS314或310S上。不同金属形成的表面氧化层不同，必须分别核实。

## 5. 附着性和耐久性怎么评价？

要区分两个概念：

- **界面附着：** 涂层与金属基底之间是否结合牢固。
- **涂层内聚：** 涂层内部催化剂颗粒之间是否结合牢固。

还要关注热循环、气流冲刷、振动和高温反应气氛下的稳定性。

从文献中提取：
- 超声频率、功率和时间；
- 测试前后的质量变化及计算方法；
- 热循环最高温度、循环次数和升降温速率；
- 气流速度和运行时间；
- 截面显微照片、元素分析和厚度变化；
- 涂层失效发生在金属界面、涂层内部还是局部裂纹处。

一次超声测试不能代替长期高温氨气环境下的寿命验证。

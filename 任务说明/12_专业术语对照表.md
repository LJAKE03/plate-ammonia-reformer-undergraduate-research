# 专业术语对照表

这份表用于帮助第一次接触本课题的同学理解专业词汇。阅读论文时，建议先查本表；写报告时，第一次出现专业术语可采用“中文名称（英文名称，英文缩写）”的写法。

## 一、反应器与结构

| 英文术语 | 中文名称 | 简单解释 |
|---|---|---|
| Ammonia decomposition / cracking | 氨分解 | 氨在催化剂作用下分解，主要生成氢气和氮气 |
| Plate reactor | 板式反应器 | 由板片或板组构成流道和反应空间的反应器 |
| Plate heat exchanger | 板式换热器 | 由多块板片形成冷热流体通道的换热设备 |
| Corrugated plate | 波纹板 | 表面具有规则波纹的金属板 |
| Channel | 流道 | 气体或液体流动的通道 |
| Manifold | 集流腔/歧管 | 将流体分配到多个通道，或将多个通道流体汇集起来的结构 |
| Flow distribution | 流量分配 | 多条并联流道之间的流量如何分配 |
| Cross-leakage | 两侧串漏 | 原本由板壁隔开的两种流体互相泄漏 |
| Counter-flow | 逆流 | 两侧流体总体流动方向相反 |
| Co-current flow | 顺流 | 两侧流体总体流动方向相同 |
| Pressure drop | 压降 | 流体经过流道后压力降低的数值 |

## 二、催化剂与涂覆

| 英文术语 | 中文名称 | 简单解释 |
|---|---|---|
| Catalyst | 催化剂 | 加快反应速率、但本身不按反应计量被消耗的物质 |
| Ru-based catalyst | 钌基催化剂 | 以钌为活性组分的催化剂 |
| Support | 载体 | 承载活性组分的材料，例如氧化铝 |
| Washcoat | 催化剂涂层/洗涂层 | 涂覆在金属或陶瓷载体表面的催化剂层 |
| Washcoating | 洗涂/催化剂涂覆工艺 | 将催化剂浆料附着到载体表面的工艺 |
| Dip coating | 浸涂 | 将基底浸入浆料后提出，使其表面留下涂层 |
| Flow coating | 流涂 | 让浆料流过指定表面形成涂层 |
| Spray coating | 喷涂 | 将浆料雾化后喷到基底表面 |
| Dip-spin coating | 旋转浸涂 | 浸涂后通过旋转甩除多余浆料 |
| Screen printing | 丝网印刷 | 利用网版和刮刀将浆料转移到指定区域 |
| Channel filling | 通道灌注/填涂 | 将浆料送入通道内部形成涂层 |
| Coating loading | 涂层负载量 | 单位面积或单位载体上附着的涂层质量 |
| Coating thickness | 涂层厚度 | 涂层从基底表面向外的厚度 |
| Adhesion | 附着性 | 涂层与基底之间结合的牢固程度 |
| Cohesion | 内聚性 | 涂层内部颗粒之间结合的牢固程度 |
| Calcination | 焙烧 | 按一定温度和气氛对材料进行热处理 |
| Activation / Reduction | 活化/还原 | 通过规定处理使催化剂达到可工作的状态 |

## 三、浆料与材料

| 英文术语 | 中文名称 | 简单解释 |
|---|---|---|
| Slurry | 浆料 | 催化剂粉末和液体等组分混合形成、可用于涂覆的混合物 |
| Solid content | 固含量 | 浆料中固体所占的质量或体积比例，必须看原文定义 |
| Viscosity | 黏度 | 衡量浆料流动阻力的物理量 |
| Rheology | 流变特性 | 材料在不同受力和流动条件下的变形、流动规律 |
| Dispersant | 分散剂 | 帮助粉末颗粒在液体中分散、减少团聚的材料 |
| Binder | 粘结剂 | 帮助颗粒之间或涂层与基底之间形成结合的材料 |
| PVA | 聚乙烯醇 | 常见水溶性有机聚合物，可用于成膜或临时粘结 |
| Glycerol | 甘油 | 一种常见有机添加剂，具体作用取决于配方 |
| Acetic acid | 乙酸 | 常用于调节体系酸度，具体作用需依据论文判断 |
| Boehmite | 勃姆石 | 氧羟化铝材料，可用于制备氧化铝相关结合层 |
| Colloidal alumina | 胶体氧化铝 | 含细小氧化铝颗粒的分散体系，可作为无机结合材料 |
| BET surface area | BET比表面积 | 通过气体吸附方法测得的材料比表面积 |

## 四、制造与检测

| 英文术语 | 中文名称 | 简单解释 |
|---|---|---|
| Substrate | 基底 | 涂层附着其上的金属或陶瓷材料 |
| Pretreatment | 表面预处理 | 涂覆前对基底进行清洁、粗化或表面改性 |
| Masking | 遮蔽 | 将不需要涂覆或加工的区域保护起来 |
| Laser welding | 激光焊接 | 利用激光热源实现材料连接 |
| Brazing | 钎焊 | 使用熔点低于母材的钎料连接零件 |
| Leak test | 气密性检测 | 检查设备是否向外泄漏 |
| Thermal cycling | 热循环 | 反复经历升温和降温的测试 |
| Ultrasonic test | 超声测试 | 利用超声作用检查涂层或材料稳定性，具体方法需看论文 |
| TDS | 产品技术说明书 | 介绍产品规格、性能和使用条件的文件 |
| SDS | 安全数据表 | 说明化学品危害、安全操作和应急措施的文件 |
| COA | 批次检验报告 | 记录某一批次产品检测结果的文件 |
| MOQ | 最小订购量 | 厂家接受订单的最低数量 |

## 五、阅读和写作时特别注意

1. “催化剂颗粒”和“涂覆用催化剂粉末”不是一回事。固定床中使用的毫米级颗粒，不能直接认定可以制成涂覆浆料。
2. “附着性”和“内聚性”不是同一个概念：前者看涂层与金属基底，后者看涂层内部。
3. “固含量”和“涂层负载量”不是同一个指标。
4. “氨转化率”“氢气产量”和“产氢速率”不是同一个指标，引用时要保留论文定义。
5. 论文没有提供的数据应写“未报告”，不能用经验值代替原始数据。

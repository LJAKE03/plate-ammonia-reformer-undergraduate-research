# A组：板式氨重整器结构与制造技术调研

## 1. 调研目标

重点研究板式氨分解反应器及与其直接相关的板式催化反应器，弄清楚它们的结构、流动组织、供热方式和制造方法。

不要把调研写成泛泛的氨制氢技术综述。固定床、管壳式和多管式反应器只作为必要的对照。

## 2. 检索年份

- 重点检索2021—2026年的研究；
- 2015—2020年的资料用于补充直接相关的结构先例和制造技术；
- 更早的资料只保留经典方法、关键结构先例或仍有参考价值的专利。

## 4. 必须提取的数据

| 类别 | 需要记录的内容 |
|---|---|
| 反应器结构 | 单板还是多层叠放；反应侧和供热侧如何布置 |
| 板片 | 材料牌号、长宽、厚度、加工方法 |
| 流道 | 高度、宽度、波纹形状、角度、节距、长度 |
| 集流结构 | 入口/出口集流腔、歧管、气体分配方式 |
| 催化剂 | 活性金属、载体、助剂、负载方式 |
| 涂覆 | 涂覆方法、负载量、涂层厚度、覆盖区域 |
| 供热 | 电加热、热气间接供热、自热等 |
| 连接 | 激光焊接、钎焊、扩散连接、垫片或机械夹紧 |
| 运行条件 | 氨气流量、温度、压力、空速和运行时间 |
| 性能 | 氨转化率、产氢量、压降、温度分布和热效率 |
| 耐久性 | 长期运行、热循环、失活、涂层脱落和两侧串漏 |

没有报告的数据写“未报告”，不能自己估算后当作论文原始数据。确需从图中读取数值时，必须标注“根据图像估算”，并说明估算方法。

## 5. 必须回答的工程问题

1. 哪些文献是真正的板式结构？哪些只是金属网、蜂窝或其他结构化载体？
2. 反应通道和热源通道怎样隔开并实现间接换热？
3. 板片如何成形、堆叠、封边和连接？
4. 入口和出口集流腔如何影响流量分配？
5. 催化剂在板片成形前还是成形后涂覆？
6. 涂覆后怎样焊接，才能尽量避免损伤催化层？
7. 板式结构的优势和局限分别是什么？
8. 现有研究是否同时报告压降、流量分配和板壁温度，而不只是氨转化率？

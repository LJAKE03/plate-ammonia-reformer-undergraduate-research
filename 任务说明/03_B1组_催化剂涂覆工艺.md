# B1组：催化剂涂覆工艺调研

## 1. 调研目标

查明商业氨分解催化剂怎样涂覆到金属板、波纹板、金属网或微通道载体上，重点判断哪些方法适合我们的**宏观波纹金属板氨气侧单面涂覆**。

## 2. 需要比较的涂覆方法

| 中文名称 | 英文名称 | 需要弄清楚的问题 |
|---|---|---|
| 浸涂 | Dip coating | 板片如何浸入浆料、提出和排液？ |
| 洗涂/浸渍涂覆 | Washcoating | 如何让催化剂浆料附着在载体表面？如何控制涂覆量？ |
| 流涂 | Flow coating | 能否只向指定一侧供浆？多余浆料如何回收？ |
| 喷涂 | Spray coating | 喷枪角度、距离、雾化和多次薄涂如何控制？ |
| 旋转浸涂 | Dip-spin coating | 旋转速度如何影响涂层厚度和均匀性？ |
| 丝网印刷 | Screen printing | 网版、刮刀和浆料能否适配波纹表面？ |
| 通道灌注/填涂 | Channel filling | 如何避免局部堆积和通道堵塞？ |

## 4. 每篇资料必须提取什么？

- 金属基底材料、形状和尺寸；
- 催化剂商品名、组成、粉末形态和粒径；
- 浆料的组成、固含量和黏度；
- 涂覆方式、速度、压力、时间和次数；
- 是否有遮蔽措施，如何控制只涂一面；
- 湿涂层和干燥/焙烧后的负载量；
- 涂层厚度、均匀性、孔隙和裂纹；
- 干燥和焙烧温度、时间、气氛及升温速率；
- 是否进行催化剂还原或活化；
- 是否测试附着性、堵塞、催化活性和长期稳定性。

## 5. 结合我们的波纹板判断工艺是否可用

重点检查：
- 波峰、波谷和斜侧壁能否都覆盖；
- 波谷会不会积液，形成局部过厚的涂层；
- 单面涂覆时，另一面会不会被浆料污染；
- 入口、出口和焊接边界是否需要遮蔽；
- 干燥收缩会不会引起裂纹；
- 涂层会不会缩小流道、增加压降；
- 大面积板片能否重复、稳定地涂覆。

首轮建议重点考察**成形后单面浸涂/洗涂和流涂**，同时把喷涂作为备选。丝网印刷可以作为批量制造方向研究，但要先证明网版能够适配波纹几何。

## 6. 最终交付

- 至少8篇有效论文或技术资料；
- 至少3篇全文精读；
- 一张涂覆工艺参数对照表；
- 一张不同涂覆方法的流程对比图；
- 对宏观波纹板的适用性分析；
- 提出2条值得进一步做小样验证的涂覆路线。

# 厂家询证与质量验收要求

## 1. 联系厂家之前

首轮联系不需要直接发送全部CAD图纸或尚未公开的研究数据。建议先发送一页项目简介和能力询问表，确认厂家是否愿意承接小批量、非标准项目。

确认企业具备相关能力后，再由项目负责人决定是否提供必要图纸。

## 2. 首轮需要询问的问题

### A. 催化剂供应
- 是否提供氨分解用途的商用钌基催化剂？
- 是否有细粉或涂覆专用粉末？
- 能否提供5—10 g实验样品？
- 是否提供产品说明书、安全数据表和批次检验报告？
- 是否有专用涂覆浆料或推荐配方？

### B. 浆料配制
- 是否接受客户提供的催化剂和配方？
- 是否能采购PVA、甘油、乙酸、勃姆石或胶体氧化铝？
- 是否能控制分散、脱泡、黏度和固含量？
- 是否能提供每批浆料的配制记录和质量报告？

### C. 催化剂涂覆
- 是否有不锈钢金属载体涂覆案例？
- 是否能对已经成形的波纹板进行单面涂覆？
- 能否覆盖波峰、波谷和斜侧壁？
- 能否控制涂覆量、厚度和均匀性？
- 是否具备干燥和焙烧设备？
- 是否能进行超声、热循环或其他附着性评价？

### D. 板片加工和连接
- 是否能按照CAD图纸加工金属波纹板？
- 是否能提供材料证明？
- 是否具备激光焊接或真空钎焊能力？
- 是否能预留无涂层的焊接区域？
- 是否有板式反应器或换热器芯体制造经验？
- 是否能进行外部泄漏和冷热侧串漏检测？

### E. 商务和交付
- 是否接受高校小批量试制？
- 最小试制数量、报价和交期是多少？
- 能否先做涂覆小样，再做完整芯体？
- 配方、工艺参数和图纸的知识产权如何约定？
- 不合格品如何返工或处理？

## 3. 三种合作方式

| 合作方式 | 具体安排 | 优点 | 主要问题 |
|---|---|---|---|
| 一体化委托 | 一家机构协调催化剂、浆料、涂覆、板片加工、焊接和测试 | 工序接口少，责任相对集中 | 能提供全部能力的厂家可能较少 |
| 专业分包 | 催化剂厂家→浆料/涂覆厂家→板片加工厂家→焊接组装厂家 | 每道工序可以选择专业企业 | 需要项目组协调质量和交接 |
| 关键工序外包 | 项目组采购催化剂和板片，委托厂家制浆、涂覆、焙烧和焊接 | 项目组对关键材料控制较多 | 项目组承担更多协调工作 |

首轮同时寻找一体化合作对象和专业分包对象，不要因为暂时找不到一家全能厂家就停止推进。

## 4. 焊接式与可拆卸式结构的比较

**焊接式芯体：** 可以减少板间可拆卸密封界面，但需要验证焊接热影响、变形、焊缝质量、冷热侧串漏以及内部涂层检查困难等问题。

**可拆卸式板组：** 便于检查、清洗和重新涂覆，但需要验证高温密封、预紧力变化、热膨胀、密封材料适用性和串漏风险。

也可以研究折中方案：内部反应芯体采用焊接密封，外部管路接口和外壳采用可拆卸连接。该方案仍需设计评审和制造验证。

## 5. 建议的质量验收项目

| 工序 | 需要记录或检查的内容 |
|---|---|
| 催化剂 | 型号、批次、钌含量、载体、粒径、产品说明书和检验报告 |
| 浆料 | 配方版本、原料批次、固含量、黏度、分散和储存记录 |
| 板片 | 材料证明、厚度、几何尺寸、波纹精度和表面状态 |
| 涂覆 | 涂覆区域、负载量、厚度、波峰/波谷/侧壁覆盖情况 |
| 干燥和焙烧 | 实际温度曲线、处理时间、气氛和批次记录 |
| 附着性 | 约定的超声、热循环或气流测试结果及测试方法 |
| 焊接 | 焊接工艺、焊缝外观、缺陷检查和热影响区检查 |
| 芯体 | 外部气密性、冷热侧串漏、流道畅通情况和耐压测试报告 |

具体合格限值应由设计要求和小样验证确定，不要在询价阶段随意设定没有依据的数值。

## 6. 公开资料与保密要求

每家企业都应记录企业名称、官网、产品或技术页面、访问日期、已经证实的能力、尚未证实的能力、联系记录和证据等级。

公开仓库中不要上传私人联系方式、非公开报价、企业保密回复或保密技术文件。

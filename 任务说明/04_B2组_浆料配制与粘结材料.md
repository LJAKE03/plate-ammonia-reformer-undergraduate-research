# B2组：催化剂浆料配制与粘结材料调研

## 1. 调研目标

围绕商用钌基氨分解催化剂，查明催化剂粉末能否用于涂覆，以及溶剂、分散剂、增稠/流变调节材料和粘结材料如何选择。

本组不负责合成钌基催化剂，也不能把不同论文的配方拼在一起。

## 2. 需要重点查明的材料

| 材料 | 常见中文名称 | 需要核实的问题 |
|---|---|---|
| Ru/Al₂O₃ | 钌/氧化铝催化剂 | 是否用于氨分解？是颗粒还是细粉？ |
| PVA | 聚乙烯醇 | 在具体配方中起成膜、临时粘结还是调节流变作用？ |
| Glycerol | 甘油 | 在原文中承担什么作用？用量如何确定？ |
| Acetic acid | 乙酸 | 是否用于调节酸碱度或帮助分散？ |
| Boehmite sol | 勃姆石溶胶 | 是否作为底涂或无机结合材料？ |
| Colloidal alumina | 胶体氧化铝 | 固含量、粒径、pH和焙烧后状态如何？ |
| Deionized water | 去离子水 | 水质要求及其与催化剂的兼容性如何？ |

注意：同一种材料在不同论文中可能承担不同作用，必须以原文为准。PVA等有机添加剂通常需要在后续热处理过程中去除；无机粘结材料也可能覆盖催化剂活性位、降低孔隙或影响气体扩散，不能只看附着强度。

## 4. 必须提取的配方和参数

| 项目 | 具体内容 |
|---|---|
| 催化剂 | 商品名、活性金属、载体、粒径、比表面积 |
| 浆料组成 | 每种组分的质量或比例 |
| 百分数基准 | 是占浆料总质量，还是相对催化剂粉末质量？ |
| 固含量 | 浆料中固体所占比例 |
| 黏度 | 数值、测试温度和剪切速率 |
| 酸碱度 | pH及测量方法 |
| 分散方法 | 机械搅拌、超声、球磨等 |
| 稳定性 | 静置沉降、分层和重新分散情况 |
| 热处理 | 干燥、焙烧温度、时间和气氛 |
| 涂层性能 | 负载量、厚度、附着性、孔隙和催化活性 |

## 5. 两套文献配方不能混用

目前有两类参考线索：
- Italiano等（2024）：商业Ru/Al₂O₃与PVA—甘油—水体系；
- Theampetch等（2019）：Ru/Al₂O₃、PVA、乙酸和水体系，研究对象为费托合成金属微通道。

两篇研究的催化剂、工艺和反应对象并不相同。必须分别记录原始配方、各组分用量和百分数基准，不能把甘油、乙酸和PVA的比例拼成一份新配方。

## 6. 最终交付

- 至少6篇与配方、浆料或粘结材料有关的资料；
- 一张原始配方对照表；
- 各组分的作用及对应证据；
- 原料采购规格和厂家询问清单；
- 商用催化剂粉末形态方面的风险分析；
- 提出1—2种值得进一步询问的浆料体系，并列出尚未验证的问题。

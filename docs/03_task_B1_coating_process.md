# 03｜任务B1：催化剂涂覆工艺调研

## 1. 目标

查明商业氨分解催化剂如何负载到金属板、波纹板、金属网或微通道载体上，重点判断哪些工艺可迁移到本项目的宏观波纹金属板单面涂覆。

## 2. 年份范围

- 直接氨分解/氨裂解催化剂涂覆：核心检索2015–2026年；2021–2026年优先。
- 通用金属载体涂覆与工业化工艺：核心检索2021–2026年；2010–2020年补充关键基础文献。
- 2009年及以前只保留经典方法来源，不作为主要文献数量。

## 4. 必须比较的工艺

| 工艺 | 重点问题 |
|---|---|
| Washcoating / Dip coating | 浸入、提出、排液、吹扫、重复涂覆如何控制？ |
| Flow coating | 如何实现单面定量供浆及多余浆料回收？ |
| Spray coating | 喷枪角度、喷距、雾化、搭接和多次薄涂如何控制？ |
| Dip-spin coating | 旋转速度如何影响涂层厚度和均匀性？ |
| Screen printing | 网版、刮刀、浆料流变和波纹表面适配如何解决？ |
| Channel filling | 如何避免通道堵塞和局部堆积？ |

## 5. 必须提取的参数

- 基底材质、几何和尺寸；
- 催化剂商品名/组成/粉末形态；
- 浆料组成、固含量和黏度；
- 涂覆方式、速度、压力、时间和次数；
- 涂覆区域及遮蔽方式；
- 湿涂层和干燥/焙烧后负载量；
- 涂层厚度、均匀性、孔隙和裂纹；
- 干燥/焙烧温度、时间、气氛和升温速率；
- 涂覆后是否进行还原活化；
- 是否评价附着性、堵塞、催化活性和耐久性。

## 6. 对本项目的评价框架

当前对象是已经成形的宏观波纹金属板，且只希望在氨气侧涂覆。评价工艺时必须检查：
- 波峰、波谷、斜侧壁是否都能覆盖；
- 波谷是否积液、形成局部厚涂层；
- 单面涂覆是否污染热侧；
- 入口/出口和焊接边界是否需要遮蔽；
- 干燥收缩是否引起裂纹；
- 涂层是否缩小流道、增加压降；
- 工艺能否在大面积板片上重复实施。

初始优先级是验证成形后的单面Washcoating/Flow coating，并将Spray coating作为并行备选。Screen printing适合后续研究批量化，但必须先证明网版能适配波纹几何。

- 至少3篇全文精读；

# 09｜厂家技术询证、合作模式与验收要求

## 1. 联系厂家前准备

首轮不必直接发送全部CAD或未公开数据。先发送一页项目简介和能力问卷，确认企业是否愿意接受小批量非标项目。只有确认具备相关能力后，再在项目负责人批准下提供必要图纸。

## 2. 首轮技术询证内容

### A. 催化剂
- 是否提供NH₃分解用途的商用Ru催化剂？
- 是否能提供细粉/washcoat-grade产品？
- 能否提供5–10 g小样？
- 是否提供TDS、SDS、COA和氨分解测试条件？
- 是否有专用涂覆浆料或推荐配方？

### B. 浆料配制
- 是否接受客户提供的催化剂和配方？
- 是否能采购PVA、甘油、乙酸、勃姆石/胶体氧化铝等材料？
- 是否能进行分散、脱泡、黏度和固含量控制？
- 是否能提供批次配制记录和质量报告？

### C. 涂覆
- 是否有不锈钢金属载体涂覆案例？
- 是否能对已成形的波纹板进行单面涂覆？
- 能否覆盖波峰、波谷和侧壁？
- 能否控制涂覆量、厚度和均匀性？
- 是否有干燥、焙烧设备？
- 是否能做超声、热循环或其他附着评价？

### D. 板片和焊接
- 是否可按CAD加工金属波纹板？
- 是否可提供材料证明？
- 是否具备激光焊接/真空钎焊能力？
- 是否能预留无涂层焊接边界？
- 是否有板式反应器/换热器芯体制造经验？
- 是否能做外部泄漏和冷热侧串漏检测？

### E. 商务和交付
- 是否接受高校小批量试制？
- 最小试制数量、报价和交期是多少？
- 是否允许先做涂覆小样再做完整芯体？
- 工艺参数、配方和图纸的知识产权如何约定？
- 不合格品和返工如何处理？

## 3. 三种合作模式

| 模式 | 组成 | 优点 | 主要风险 |
|---|---|---|---|
| 一体化 | 一家机构协调催化剂、浆料、涂覆、板片、焊接和测试 | 接口少、责任集中 | 供应商少、成本和排期不确定 |
| 专业分包 | 催化剂商→浆料/涂覆商→板片商→焊接组装商 | 可选择专业团队 | 需要项目方管理接口和质量 |
| 核心工序外包 | 项目方采购催化剂和板片，外包制浆/涂覆/焙烧及焊接 | 技术控制较多 | 项目方承担协调与质量衔接 |

首轮同时寻找一体化合作对象和专业分包对象，不因找不到全能厂家而停止推进。

## 4. 首台样机的连接方案比较

### 焊接式芯体
优点：减少板间可拆卸密封界面，适合形成封闭流道。  
需要验证：焊接热影响、变形、焊缝缺陷、冷热侧串漏、内部涂层检查困难。

### 可拆卸式板组
优点：便于检查、清洗和重新涂覆。  
需要验证：高温密封、预紧力衰减、热膨胀、垫片/金属密封适用性、串漏风险。

### 当前候选折中方案
研究焊接密封的内部反应芯体，外部管路接口和外壳采用可拆卸连接；必要时把芯体设计成可整体更换的模块。该方案仍需设计评审和制造验证。

## 5. 建议的质量验收点

| 工序 | 交付/检验项目 |
|---|---|
| 催化剂 | 型号、批次、Ru含量、载体、粒径、TDS/SDS/COA |
| 浆料 | 配方版本、原料批次、固含量、黏度、分散和储存记录 |
| 板片 | 材料证明、厚度、几何尺寸、波纹精度、表面状态 |
| 涂覆 | 涂覆区域、负载量、厚度、波峰/波谷/侧壁覆盖、见证试片 |
| 干燥焙烧 | 实际温度曲线、时间、气氛和批次记录 |
| 附着 | 约定的超声/热循环/气流测试结果，记录测试方法 |
| 焊接 | 焊接工艺、焊缝外观、缺陷检查、热影响区检查 |
| 芯体 | 外部气密、冷热侧串漏、流道畅通、耐压测试报告 |

具体限值由设计和小样验证确定，不得在询价阶段随意设定没有依据的合格数值。

## 6. 公开信息与证据等级

每个厂家条目必须包含：
- 企业名称和官网；
- 产品/技术页面；
- 访问日期；
- 已证实能力；
- 尚未证实能力；
- 联系记录；
- 证据等级A/B/C/D。

不要在公开仓库保存私人联系人信息、非公开报价或保密技术文件。

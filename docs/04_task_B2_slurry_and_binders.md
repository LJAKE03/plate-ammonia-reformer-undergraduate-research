# 04｜任务B2：浆料配制、流变与粘结材料

## 1. 目标

围绕已选定的商用Ru基氨分解催化剂，查明其粉末形态能否用于涂覆，以及浆料溶剂、分散剂、流变调节剂和无机粘结相如何选择。

本工作包不负责合成Ru催化剂，也不自行拼接文献配方。

## 2. 年份范围

- 商用Ru基氨分解催化剂及其浆料：2015–2026年，优先2021–2026年。
- 通用金属载体washcoat、浆料流变和无机粘结剂：2021–2026年优先；2010–2020年补充基础研究。
- 经典材料机理文献可保留，但需说明其年代和对象。

## 4. 组分功能必须分清

| 组分 | 可能作用 | 必须核实的问题 |
|---|---|---|
| Ru基催化剂粉末 | 活性催化材料 | 是否为氨分解专用；是否为涂覆级细粉 |
| 去离子水/其他溶剂 | 连续相、溶剂 | 是否与催化剂及添加剂兼容 |
| PVA | 成膜/临时粘结或流变调节 | 具体文献中承担何种作用；水解度和分子量 |
| 甘油 | 分散/流变调节等 | 原文定义、用量、是否影响干燥 |
| 乙酸 | 酸度调节/胶溶或分散辅助 | 是否改变催化剂表面化学及活性 |
| 勃姆石溶胶 | 氧化铝前驱体/无机结合相 | 是否作为底涂或浆料添加剂 |
| 胶体氧化铝/氧化铝溶胶 | 无机粘结相 | 固含量、粒径、Na杂质、pH和焙烧后相 |
| 硅溶胶 | 无机结合相 | Si引入是否影响催化活性 |
| 其他有机添加剂 | 分散、流变、消泡 | 焙烧残留和孔隙影响 |

PVA通常不是在高温反应中长期保留的永久粘结剂。必须查明其在干燥和焙烧阶段的去除行为。无机粘结相也可能覆盖活性位、降低孔隙或改变扩散，不能只按附着性判优。

## 5. 重点比较指标

- 催化剂粒径D10/D50/D90及测试方法；
- 粉末比表面积和孔容；
- 浆料固含量；
- 每种添加剂的质量比例及分母；
- pH及测量方法；
- 黏度、剪切速率、测试温度；
- 触变/剪切变稀；
- 静置沉降和再分散性；
- 球磨/超声/机械搅拌条件；
- 焙烧后质量损失、孔隙和活性；
- 涂层负载量、附着和裂纹。

## 6. 两套已有文献配方只能分别记录

项目资料中有两类参考：
- Italiano et al. (2024)：商业Ru/Al₂O₃与PVA—甘油—水体系；
- Theampetch et al. (2019)：Ru/Al₂O₃、PVA、乙酸和水体系，研究对象为费托合成金属微通道。

它们的催化剂、工艺和反应对象不同。学生必须保留各自原始配方和百分数基准，不得把甘油、乙酸和PVA比例拼成一份新配方。

## 7. 交付物

- 不少于6篇配方/浆料/粘结材料文献；
- 完整配方对照表；
- 每种组分的功能和证据；
- 原料供应规格询问清单；
- 商用催化剂粉末形态风险分析；
- 对本项目建议优先询问的1–2种浆料体系及其未验证项。

# 00｜项目简介与技术边界

## 1. 研究对象

本项目研究层叠式板式催化氨分解反应器。氨气在催化剂涂覆侧流动并发生分解；热源气体在相邻独立流道内流动，通过金属板壁向反应侧间接供热。热源气体不进入氨反应通道。

本科生本轮工作的重点是查明：这种结构如何制造、催化剂如何负载、涂层如何保持稳定、哪些企业能够提供定制服务。

## 3. 本轮要解决的工程问题

### 催化剂与浆料
- 商用Ru基氨分解催化剂是否有适合涂覆的粉末形态？
- 固定床颗粒能否获得同体系细粉或专用washcoat-grade产品？
- 浆料由课题组配制还是委托厂家配制？
- PVA、甘油、乙酸、勃姆石/胶体氧化铝分别承担什么作用？

### 金属板与涂层
- 先成形再涂覆，还是先涂覆再成形？
- 如何只涂覆氨气侧？
- 波峰、波谷和侧壁能否均匀覆盖？
- 如何控制涂层厚度、负载量、孔隙和流道堵塞？
- 如何评价金属—涂层界面附着及涂层内部内聚？

### 连接与制造
- 涂覆、干燥、焙烧和焊接的顺序如何安排？
- 如何预留不涂覆的焊接区域（welding land）？
- 焊接热影响区是否损伤催化剂涂层？
- 焊接芯体与可拆卸结构的密封、维护和制造风险如何比较？

### 供应链
- 是否有厂家可以提供商用催化剂、浆料代配、金属板涂覆和焊接组装？
- 如果没有一体化厂家，如何分包并控制各工序接口？
- 厂家是否接受高校小批量试制？

## 4. 首轮制造路线假设

当前优先验证的候选流程：

板片成形 → 清洁/表面预处理 → 遮蔽焊接边界 → 氨侧单面涂覆 → 干燥/焙烧 → 涂层质量验收 → 堆叠及焊接 → 气密性和冷热侧串漏检测。

这是待验证的候选路线，不是已经批准的最终工艺。学生必须同时评估“组装后内部涂覆”等替代路线，并解释其适用条件。

## 5. 本科生工作边界

本轮是“找方法、找技术、找合作方”，不是让本科生自行开发Ru催化剂或独立操作危险反应系统。学生交付应以可核查的文献数据、工艺流程、供应商能力证据和明确的待确认问题为主。

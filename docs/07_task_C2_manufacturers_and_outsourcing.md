# 07｜任务C2：催化剂涂覆、金属板加工与反应器制造外包

## 1. 目标

寻找能够接受高校科研项目小批量非标定制的制造企业或技术机构。重点不是找普通产品经销商，而是确认实际加工设备、工艺经验和交付能力。

## 2. 需要寻找的企业类别

1. 催化剂涂覆加工商；
2. 汽车尾气/工业催化剂浆料制备企业；
3. 金属板冲压、压制、辊压成形企业；
4. 激光焊接、真空钎焊、扩散连接企业；
5. 微通道/板式反应器制造企业；
6. 能够提供一体化设计、加工、涂覆和组装的技术机构。

## 6. 必须比较的外包模式

### 模式一：一体化定制
一个技术机构协调催化剂、浆料、涂覆、板片制造、焊接和整机测试。

### 模式二：专业分包
催化剂供应商 → 浆料/涂覆商 → 板片加工商 → 焊接组装商。项目方负责技术接口和验收。

### 模式三：核心工序外包
项目方采购催化剂并提供板片CAD，外包涂覆和焙烧，另由专业加工商焊接组装。

比较维度：质量责任、工艺衔接、交期、成本、知识产权、返工能力、批次追溯和小批量可行性。

## 7. 建议优先研究的工序顺序

候选路线A：
板片成形 → 表面预处理 → 遮蔽焊接边界 → 单面涂覆 → 干燥/焙烧 → 涂层检验 → 堆叠焊接 → 焊缝及气密性检查。

必须向厂家确认：
- 涂层是否会污染焊接区域；
- 焊接热影响区是否损伤涂层；
- 焊接夹具如何定位；
- 焊后是否需要再热处理；
- 内部涂层是否能通过见证试片和过程记录验收。

候选路线B：
先组装板芯 → 从内部通道进行填涂/流涂 → 排液/干燥/焙烧 → 检验。

必须确认内部涂覆是否能控制单面、厚度和覆盖均匀性，以及是否会堵塞通道。

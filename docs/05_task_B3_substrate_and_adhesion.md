# 05｜任务B3：金属基底、表面处理与涂层附着

## 1. 目标

找出适合高温氨分解板式反应器的金属基底候选，并研究如何通过表面预处理、底涂和无机结合相提高催化剂涂层附着与耐久性。

## 2. 年份范围

- 金属载体氨分解直接证据：2015–2026年，优先2021–2026年。
- 金属基底washcoat附着和热循环研究：2021–2026年优先；2010–2020年补充。
- 经典底涂/勃姆石/氧化铝涂层方法可保留代表性早期文献。

## 4. 基底候选必须分别比较

| 材料 | 研究重点 |
|---|---|
| SS314 / EN 1.4841 | 现有氨分解微通道研究中的直接材料参照；核对高温氨气氛适用性 |
| 310S / EN 1.4845 | 询价和材料对比候选；不得写成与SS314完全等同 |
| 316L | 关注高温氨气氛和渗氮/脆化风险，不可仅依据常温耐蚀性 |
| IN625 | 高温结构化催化剂的高成本候选，评估成本和加工性 |
| FeCrAl | 有较多金属载体预氧化和氧化铝涂层研究，但与SS314不是同一表面体系 |

## 5. 重点研究的表面处理

- 脱脂和清洗；
- 喷砂/机械粗化；
- 酸洗或碱洗；
- 可控预氧化；
- 氧化铝或勃姆石底涂；
- 等离子/粉末喷涂中间层；
- 焊接边界遮蔽。

特别注意：FeCrAl上的高温预氧化制度不能直接照搬到SS314或310S。每种材料的表面氧化层组成、附着和高温氨气氛行为必须分别核实。

## 6. 附着性评价

必须区分：
- 界面附着：涂层与金属基底结合；
- 涂层内聚：催化剂颗粒之间结合；
- 热循环稳定性；
- 气流冲刷/振动耐久；
- 反应气氛下的长期稳定性。

提取：
- 测试介质、超声频率/功率/时间；
- 测试前后质量及计算方法；
- 热循环最高温度、循环次数、升降温速率；
- 气流速度和运行时间；
- 截面SEM、EDS和厚度变化；
- 失效位置是金属界面、涂层内部还是局部裂纹。

单次超声测试不能代替长期高温氨气氛寿命验证。

## 7. 交付物

- 基底材料对照表；
- 表面处理工艺对照表；
- 无机粘结相/底涂材料对照表；
- 附着与耐久测试矩阵；
- 对本项目首轮金属小样验证的建议；
- 需要向板材和涂覆厂家确认的材料问题。

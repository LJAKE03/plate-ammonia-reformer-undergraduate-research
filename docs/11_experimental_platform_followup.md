# 11｜实验平台：本轮暂缓，待样机制造方案明确后修订

## 1. 当前定位

实验平台建设不是本轮本科生工作的主任务。先完成结构、催化剂、浆料、涂覆和制造链条调研，再根据真实样机尺寸、接口、材料和工况确定平台。

当前仍以独立可控热源气体供热为实验平台基础设想，不提前转为发动机实机排气联合运行。

## 2. 后续平台分阶段

### 阶段I：冷态与密封验证
- 惰性气体气密性；
- 外部泄漏；
- 热侧/氨侧串漏；
- 流道畅通；
- 冷态压降；
- 流量分配。

### 阶段II：非反应换热
- 独立热气供给；
- 冷侧惰性气体或经批准的替代工质；
- 入口/出口温度；
- 板壁温度；
- 两侧压力和压降；
- 热量平衡和测量不确定度。

### 阶段III：催化反应
- 催化剂活化/还原；
- NH₃供给和尾气处理；
- NH₃转化率；
- H₂产量和产品气组成；
- 运行稳定性和催化剂失活；
- 高温涂层和结构完整性。

## 3. 平台参数需要等什么信息？

| 平台部件 | 需要先明确的信息 |
|---|---|
| MFC | 反应器设计流量、气体种类、压力和量程 |
| 热源加热器 | 热侧流量、入口温度、目标热负荷和允许压降 |
| 热电偶 | 板片结构、测点可达性、温度范围和安装方式 |
| 压力传感器 | 设计压力、压降范围和测压口位置 |
| GC | 预期产品组成、检测限、采样方式 |
| 尾气处理 | NH₃残余量、H₂/N₂组成、排放和安全要求 |
| 控制与联锁 | 气体切断、超温、超压、通风、泄漏检测和紧急停机 |

## 4. 安全边界

涉及NH₃、H₂、催化剂还原、高温和压力系统的工作必须由项目负责人组织安全评审。学生只能在授权、培训和批准的程序下参与。不得自行购买气体、接管路、改动联锁或进行反应试验。

## 5. 本轮交付

每个工作包只需提出与其技术方向相关的平台影响。例如涂覆工艺负责人指出涂层厚度会影响流道尺寸；制造负责人指出需要预留测温/测压接口。完整设备清单和采购预算留到样机方案冻结之后。

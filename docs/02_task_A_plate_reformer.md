# 02｜任务A：板式氨重整器结构与制造技术调研

## 1. 调研范围

唯一核心对象：板式氨分解/氨重整反应器，以及与其直接相关的板式催化反应器。

不做泛泛的氨制氢技术综述。固定床、管壳式、多管式只作为必要的对照，不作为主要检索对象。

## 2. 年份范围

- 核心检索：2021–2026年。
- 补充检索：2015–2020年，限于直接板式氨分解研究、关键结构先例或高价值制造技术。
- 经典方法文献：2014年及以前，只保留能够解释关键工艺或被后续研究反复引用的代表性来源。
- 专利：优先2021–2026年公开/申请的专利，同时追溯仍有效且高度相关的早期专利。

## 4. 数据提取清单

| 类别 | 必须提取 |
|---|---|
| 结构 | 单板/叠层、反应侧/热侧布置、并联/串联、逆流/错流 |
| 板片 | 材料牌号、板长宽、板厚、加工方法 |
| 流道 | 高度、宽度、波纹形状、角度、节距、长度 |
| 集流 | 入口/出口集流腔、歧管、分配方式 |
| 催化剂 | 活性金属、载体、助剂、负载方式 |
| 涂覆 | 工艺、负载量、涂层厚度、覆盖区域 |
| 供热 | 电加热、热气间接供热、自热等 |

| 耐久 | 热循环、长期运行、失活、涂层脱落、串漏 |

所有缺失数据写“未报告”，不得通过图像估算后冒充原文数值。若确需从图中数字化，应单独标注“图像数字化估算”，说明软件和不确定性。

## 5. 必须回答的工程问题

1. 哪些文献真正属于板式结构？哪些只是金属网、蜂窝或其他结构化载体？
2. 反应通道与热源通道怎样隔开并实现间接换热？
3. 板片如何形成、堆叠、封边和连接？
4. 入口/出口集流腔如何减少流量不均？
5. 催化剂是在成形前还是成形后涂覆？
6. 涂覆后如何完成焊接而不破坏催化层？
7. 板式结构的优势和限制分别是什么？
8. 现有研究是否报告了压降、流量分配和板壁温度，而不只是转化率？

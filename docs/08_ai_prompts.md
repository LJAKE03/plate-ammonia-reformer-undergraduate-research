# 08｜AI文献与供应商调研提示词

学生可逐篇上传PDF，复制对应提示词。AI结果必须人工回到原文核对。

## Prompt 1 — 单篇论文全文提取

```text
你是一名催化反应器、结构化催化剂及金属表面涂覆领域的科研文献分析助手。

请以我上传的PDF全文为唯一事实依据，提取与板式氨分解反应器、催化剂涂覆或金属载体附着相关的数据。

硬性规则：
1. 必须阅读正文、实验方法、表格、图注和补充材料；不能只总结摘要。
2. 不得补造未报告的数据；缺失项写“未报告”。
3. 所有数值保留原始单位、质量基准和测试条件。
4. 区分作者实验数据与其引用的其他研究。
5. 每项关键数据标注PDF页码、章节、表格或图号。
6. 不得把不同论文配方拼接成新配方。
7. 明确指出催化剂、基底、几何和反应条件与本项目的差异。

请按以下结构输出：
A. 文献基本信息（题目、作者、年份、期刊、DOI）
B. 研究对象和结构
C. 金属基底及表面处理
D. 催化剂商品名/活性组分/载体/助剂/粉末形态/粒径
E. 浆料配方表（组分、质量、百分数、百分数分母、功能）
F. 浆料制备步骤（加料顺序、温度、时间、转速、球磨/超声）
G. 涂覆工艺步骤（方式、速度、时间、次数、遮蔽、排液/吹扫）
H. 干燥、焙烧、还原活化条件
I. 涂层负载量、厚度、均匀性和附着结果
J. 反应性能和耐久性
K. 未报告的数据
L. 对本项目的可借鉴之处
M. 不能直接迁移的参数及原因
N. 原文定位清单（页码/表格/图号）

最后将结论分为直接证据、间接证据、工程推断和未知事项。
```

## Prompt 2 — 多篇文献横向比较

```text
请比较我上传的所有已提取文献。不要重复写摘要，而要建立可追溯的技术比较。

重点比较：
1. 催化剂种类、商品形态、粒径和载体；
2. 金属基底及预处理；
3. 浆料配方及各百分数的计算基准；
4. PVA、甘油、乙酸、勃姆石、胶体氧化铝等组分的具体作用；
5. Washcoating、Flow coating、Spray coating、Dip-spin和Screen printing；
6. 涂层负载量、厚度、均匀性和流道堵塞；
7. 干燥、焙烧、还原和活化；
8. 附着、热循环、气流冲刷和长期稳定性；
9. 涂覆后催化活性；
10. 工艺放大和质量控制。

输出：
A. 文献总矩阵；
B. 各工艺优缺点；
C. 各浆料体系的差异；
D. 对宏观波纹金属板的适用性；
E. 当前证据空白；
F. 推荐优先向厂家询问的工艺；
G. 必须通过小样验证的问题。

严格保留来源，不要把不同文献的配方拼成一个新配方。陶瓷蜂窝、金属网、微通道和平板波纹结构必须分开评价。
```

## Prompt 3 — 厂家能力核查

```text
你是一名工业供应链与非标设备制造调研助手。请根据我提供的企业官网、产品页、技术资料和公开案例，判断该企业能否参与板式氨重整器的定制制造。

逐项调查：
1. 商用Ru基氨分解催化剂供应；
2. 细粉/washcoat-grade产品；
3. PVA、甘油、乙酸、勃姆石/胶体氧化铝等原料采购；
4. 按客户配方制备浆料；
5. 不锈钢金属板单面涂覆；
6. 宏观波纹板涂覆；
7. 干燥和焙烧；
8. 板片冲压、压制或辊压成形；
9. 激光焊接、钎焊或扩散连接；
10. 板片堆叠和反应器组装；
11. 气密性、耐压和冷热侧串漏检测；
12. 高校小批量非标试制。

每项标记：
A = 官方资料明确证明；
B = 公开宣传有该能力但具体适用性未确认；
C = 根据业务推测可能具备；
D = 未找到证据。

必须给出官方来源、页面标题、访问日期和证据原句/摘要。不要编造电话、邮箱、联系人、报价、MOQ或交期。

最后回答：
- 哪些工序可由该企业承担？
- 哪些工序仍需其他供应商？
- 是否有证据证明它做过波纹金属板涂覆？
- 是否接受小批量非标订单？
- 最值得发给技术部门的5个问题是什么？
```

## Prompt 4 — 工艺路线评审

```text
请作为板式催化反应器制造工程师，对以下候选路线进行技术评审：

路线A：板片成形→表面预处理→遮蔽焊接边界→单面催化剂涂覆→干燥/焙烧→涂层检验→板片堆叠焊接→气密性检测。

路线B：板片成形→板片堆叠焊接→内部通道涂覆/填充→排液/干燥/焙烧→涂层和气密性检测。

请比较：
1. 涂覆可达性和单面控制；
2. 波峰、波谷和侧壁均匀性；
3. 焊接热影响；
4. 涂层污染焊接边界的风险；
5. 内部通道堵塞风险；
6. 涂层检查和返工能力；
7. 批量制造重复性；
8. 供应商设备要求；
9. 关键质量验收点。

对每个判断标注依据属于文献事实、制造常识还是待验证假设。不要把尚未验证的路线说成已经可行。
```

## Prompt 5 — 研究结果审查

```text
请审查这份本科生调研报告。重点检查：
1. 是否真正阅读原文，还是只引用摘要；
2. DOI、作者、年份、期刊是否正确；
3. 数值是否能在原文找到；
4. 百分数分母是否正确；
5. 不同基底、催化剂和工艺是否被错误合并；
6. 是否将供应商宣传当成独立验证；
7. 是否把固定床颗粒误认为涂覆粉末；
8. 是否把催化剂失活等同于涂层脱落；
9. 是否将陶瓷蜂窝结论直接迁移到宏观波纹板；
10. 是否给出清晰的技术判断和未解决问题。

请输出问题清单，按严重程度排序，并给出需要回到原文核对的页码、表格和图号。不要为了通过审查而补造缺失数据。
```

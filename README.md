# 板式氨重整器本科生开放研究手册

本仓库用于组织六名本科生参与《船用发动机板式氨重整器结构优化与制氢特性研究》相关的工程调研。当前阶段重点不是开展大规模数值计算，而是**寻找可行的技术方法、制造工艺、材料供应商和定制加工合作方**，为后续重整器样机制造与比赛项目积累资料。

> 本仓库是开放式研究工作手册，不是最终设计文件或制造规范。文中的结构尺寸、材料、催化剂、浆料和工艺路线均为调研参考，必须经过项目负责人和导师确认后才能用于采购或制造。

## 一、研究对象与当前任务

研究对象为层叠式板式催化氨分解反应器：氨气在催化剂涂覆侧流动并发生分解；热源气体在相邻独立流道内流动，通过金属板壁向反应侧间接供热，热源气体不进入氨反应通道。

当前工程模型的参考参数包括：约652 mm × 192 mm的几何尺寸、2 mm板厚、4 mm流道高度、60°波纹角度和10 mm波纹法向节距。这些参数仅用于帮助理解现有设计，不是冻结的样机尺寸或采购图纸。

本轮需要优先回答四类问题：

1. **板式结构如何制造：** 板片成形、流道和集流腔、板组堆叠、封边及连接方式。
2. **催化剂如何涂覆：** 商用Ru基催化剂能否获得适合涂覆的粉末；如何制浆、单面涂覆、干燥和焙烧；如何保证涂层均匀、附着且不堵塞流道。
3. **制造链条如何外包：** 是否能由供应商代购催化剂、按配方制浆、涂覆金属波纹板，并完成板片加工、焊接和气密检测；如果没有一体化厂家，如何分工外包。
4. **实验平台如何衔接：** 先明确样机结构、材料、接口和工况，再修订实验平台，不提前采购尚未定型的设备。

## 五、候选制造路线

首轮重点比较两条路线，不得把其中任何一条直接当作已验证方案：

**路线A：先涂覆板片，再连接成芯体**

板片成形 → 清洁和表面预处理 → 遮蔽焊接边界 → 氨侧单面涂覆 → 干燥/焙烧 → 涂层检验 → 堆叠和焊接 → 外部气密及冷热侧串漏检测。

**路线B：先连接成芯体，再进行内部涂覆**

板片成形 → 堆叠/焊接 → 内部通道涂覆或填充 → 排液/干燥/焙烧 → 涂层与气密性检查。

路线A的优势是涂覆可达性较好，但要验证焊接边界遮蔽、热影响区和焊后质量；路线B要重点验证内部单面涂覆的可达性、均匀性和堵塞风险。也要比较焊接式芯体与可拆卸板组的密封、维护和返工代价，不能简单认定某种结构必然漏气。

## 六、证据与AI使用规范

每条结论标注证据等级：

- **A：直接核实**——原始论文、专利、官方技术文件或企业书面回复明确支持。
- **B：间接支持**——相关材料或相近结构有证据，但与本项目存在差异。
- **C：线索/推断**——由企业业务或相邻技术推测，尚未确认。
- **D：未知**——没有可靠证据。

上传论文给AI时，要求它提取原文中的工艺、配方、参数、单位和页码/图表位置。AI输出必须人工回到PDF核对。未报告的数据写“未报告”，不得补造。不同论文的配方不得拼接；固定床毫米级颗粒不能直接视为可涂覆粉末；陶瓷蜂窝、金属网、微通道和宏观波纹板的结论必须区分。

## 七、安全与公开仓库边界

本科生本轮负责资料检索、技术比较和供应商初步联系，不得自行开展氨气/氢气实验、催化剂还原活化、高温压力测试或气路改造。相关工作必须经过项目负责人组织的安全评审，并按实验室批准程序执行。

本仓库为公开仓库：不得上传完整受版权保护的论文PDF、私人联系方式、非公开报价、企业保密回复、未公开原始实验数据、专有CAD文件或服务器仿真文件。公开文献只记录规范书目信息、DOI/官方链接和允许分享的摘录。

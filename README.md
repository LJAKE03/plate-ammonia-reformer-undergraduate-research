# 板式氨重整器本科生研究手册

欢迎参与本项目。本仓库用于组织六名本科生开展板式氨重整器相关工程调研。**本轮工作的重点是查方法、查材料、查厂家，弄清楚反应器怎样制造、催化剂怎样涂覆，以及后续怎样做成样机。**

本手册尽量使用中文。必要的英文专业术语会在后面标注中文解释，方便大家查阅论文和联系厂家。

> **先说明：** 本仓库是调研工作手册，不是最终设计图纸或制造规范。文中的结构尺寸、材料、催化剂、配方和工艺路线都只是研究参考，必须经过项目负责人和导师确认后才能用于采购或制造。

## 一、先花10分钟了解研究对象

我们研究的是一种层叠式板式催化氨分解反应器：

- **反应侧：** 氨气流过涂有催化剂的一侧，在催化剂作用下分解并产生氢气和氮气。
- **供热侧：** 热源气体在相邻的独立流道中流动，通过金属板壁向反应侧传热。
- 两侧由金属板壁隔开，热源气体不进入氨气反应通道。

本轮调研主要回答四个问题：

1. 板片、流道、集流腔和反应器芯体怎样加工和连接？
2. 商用钌基催化剂怎样制成浆料，并涂覆到波纹金属板上？
3. 涂层怎样保持均匀、牢固，同时不堵塞流道？
4. 哪些企业能提供催化剂、浆料代配、金属板涂覆、焊接和组装服务？

## 四、专业术语看不懂怎么办？

仓库专门准备了[专业术语对照表](任务说明/12_专业术语对照表.md)。例如：

- Washcoating：催化剂洗涂/涂覆工艺；
- Slurry：浆料；
- Binder：粘结剂；
- Substrate：基底；
- Adhesion：涂层与基底之间的附着性；
- Manifold：集流腔或歧管。

不用一开始就记住所有英文。先理解中文意思，阅读论文或搜索资料时再使用英文关键词。

## 六、调研时必须遵守的原则

1. **不要只看摘要。** 尽量阅读论文全文和实验方法。
2. **不要编数据。** 没有报告就写“未报告”。
3. **不要拼配方。** 不同论文中的催化剂和配方不能随意组合。
4. **不要混淆产品形态。** 固定床用毫米级催化剂颗粒，不等于可以直接制成涂覆浆料。
5. **不要把相近技术当成相同技术。** 陶瓷蜂窝、金属网、微通道和平板波纹结构需要分别判断。
6. **不要把厂家宣传当成已验证能力。** 需要询问是否做过类似材料、尺寸和工艺，是否接受小批量订单。
7. **不要上传保密资料。** 本仓库是公开仓库，不得上传私人联系方式、非公开报价、保密回复、未公开实验数据和专有CAD图纸。

## 七、实验平台先不急着采购

实验平台的后续安排见[实验平台后续规划](任务说明/11_实验平台后续规划.md)。先把反应器结构、制造路线和样机参数弄清楚，再确定流量控制器、加热器、传感器和气体分析设备。

涉及氨气、氢气、高温和压力系统的实际操作，必须经过项目负责人批准和实验室安全培训。不得自行操作。
